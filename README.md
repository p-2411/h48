# Duet

Duet is a local-first Japanese learning companion for understanding nuanced lines, practising them with a voice tutor, and reviewing contextual cards with FSRS.

The active product implementation is in [`app`](./app). The repository also retains the original browser-extension experiment in [`Draft1_extension`](./Draft1_extension) and the deployed marketing site in [`waitlist`](./waitlist).

## Run the product

```powershell
cd app
npm install
npm run dev
```

See [`app/README.md`](./app/README.md) for architecture, data storage, optional provider configuration, and verification commands.
